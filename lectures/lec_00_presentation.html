Today in one sentence

In this course you learn how computer scientists approach everyday decisions, and how to turn these ideas into Python code.

Why it matters

More and more business decisions rely on data and algorithms. You don’t need to become a programmer, but understanding how algorithms think, and writing a few lines of code yourself, makes you a better decision maker. No prior knowledge required.

Lecture: presentation and discussion of algorithms related to everyday decision-making. Tutorial: step-by-step assignments to be solved and discussed together in groups. Difficulty: strongly depends on your background and programming experience.

How you pass

  • Pass/fail course without exams
  • 75% attendance required
  • Two assignments on algorithmic problems from the course
  • Short final presentation of your prototype in the last lecture
  • You can work in groups of up to three students

How to hand in assignments

  • Each group submits one solution per assignment
  • Hand in your working notebooks
  • Due by the end of the quarter, earlier is better
  • At least 50% of the solutions have to be correct

Earlier submissions are highly encouraged: you get feedback while the topic is still fresh.

Why Python?

  • Simple syntax: easy to read and to learn
  • Versatile: web, data analysis, artificial intelligence
  • Big community: help and documentation everywhere

Origins: Python was conceived in the late 1980s as a teaching and scripting language. Its syntax is mostly straightforward and very easy to learn. It is used in web development, data analysis, artificial intelligence and more, and it has a large community of users worldwide with extensive documentation.

Three habits that work

  1. Be present: attend the lecture and solve the tutorials
  2. Put in some work: repeat code and try to understand it
  3. Do coding: run code, play around, modify, and solve

Great resources to start are books (see the list at the end of the lecture) and small challenges, for example on Codewars.

Don’t give up!

  • Programming is problem solving, errors are normal
  • Expect to stretch your comfort zone

VS Code is an IDE

  • IDE = Integrated Development Environment, an app to write, run and debug code
  • Other IDEs: PyCharm, Zed

Install Python with uv

  • uv installs Python and manages packages for us
  • It works on Windows, Mac and Linux
  • Now we all go here and install uv and Python

If the installation does not work, let us know!

Quick check

Something not working yet? Ask us!

Add notebooks to your project

  • Run uv add --dev ipykernel in your terminal
  • Then run uv add jupyter
  • Now notebooks can use the Python of your project

The first command adds a kernel to the project, the second the Jupyter tools. Done? Perfect, now we can start.

Download a tutorial and open it

  • Open a tutorial on the website and select Jupyter on the right
  • Save the file to your course folder
  • Open it in VS Code and select “Open with Jupyter Notebook”

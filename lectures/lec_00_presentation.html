VS Code is where you write code

  • Like Word for text, but for code: an app to write, run and find mistakes in code
  • Apps like this are called IDEs (Integrated Development Environments)
  • We use VS Code for the whole course

Other IDEs exist, for example PyCharm or Zed. We use VS Code because it is free, works on all systems and has good notebook support. Every step of the setup is in the Installation Guide on the website, with a check at the end of each step.

The terminal: typing instead of clicking

  • A window where you type a command, press Enter, and the computer answers with text
  • No menus, no buttons: the computer does exactly what you typed
  • We need it only for the setup: a handful of commands, all in the guide to copy

The terminal lives inside VS Code, as a panel at the bottom. On a Mac the line ends with a percent sign, on Windows it starts with PS for PowerShell. Nobody needs to memorise commands: during the setup, you copy them from the guide, paste them and wait until the line is back.

uv installs Python for us

  • uv is a small helper tool: it installs Python and everything Python needs
  • Everyone gets the same Python version, so code works the same on every laptop
  • You install uv once, then it does the rest for you

Without a tool like uv, every laptop ends up with a slightly different Python, and we would spend the tutorials fixing setups instead of programming. uv also keeps each project in its own folder with its own packages, so nothing gets mixed up.

Notebooks mix text and code

  • A notebook is a document with text cells and code cells
  • You run a code cell, and the result appears right below it
  • All tutorials are notebooks: read, run, change, try again

Notebooks are ideal for learning: you see a short explanation, run a few lines, and immediately see what happens. VS Code opens them with the Jupyter extension. The tutorials on the website can be downloaded as notebooks under “Other Formats”.
